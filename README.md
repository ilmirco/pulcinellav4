# Pizzeria Pulcinella — sito con configuratore

Sito statico ufficiale per https://www.pulcinellapatu.it/. Pubblicazione GitHub Pages dal ramo `main`, cartella principale; nessun servizio di composizione esterno o server applicativo.

Home, configuratore in dieci lingue, riepilogo locale e PDF, privacy e pagina 404. Il configuratore prepara un riepilogo per il cliente; gli ordini si effettuano telefonicamente.

Il sito precedente rimane conservato in https://github.com/ilmirco/pulcinellav3.

Versione preparata il 25 ottobre 2026 dalla copia approvata, commit `ffe4d2f`, con risorse del configuratore `190ecca`. Font e librerie mantengono gli avvisi di licenza nelle rispettive cartelle.
