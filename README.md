# Pizzeria Pulcinella — sito con configuratore

Sito statico ufficiale per https://www.pulcinellapatu.it/. Pubblicazione GitHub Pages dal ramo `main`, cartella principale; nessun servizio di composizione esterno o server applicativo.

Home, configuratore in dieci lingue, riepilogo locale e PDF, privacy e pagina 404. Il configuratore prepara un riepilogo per il cliente; gli ordini si effettuano telefonicamente.

Il sito precedente rimane conservato in https://github.com/ilmirco/pulcinellav3.

Rilascio del 6 novembre 2026: configuratore mobile nel cartone bianco, sfondo bianco farina, tendina trascinabile, porzioni, confezionamento animato e carrello completo. Restano disponibili Annulla, Riparti dalla Margherita (sul gusto attivo nei formati lunghi) e La tua pizza da vicino. Tutte le dieci lingue condividono il catalogo esistente. La lista usa la stessa memoria locale della versione precedente. Il configuratore desktop conserva l'interfaccia originale.

La hero mobile usa una codifica VP9 meno compressa (circa 3,04 MB), MP4 di riserva e nuovo poster. Il video 1080×1920 deriva dal master 720×1280 con lieve nitidezza: non è una sorgente Full HD nativa. Video e stile desktop restano invariati.
